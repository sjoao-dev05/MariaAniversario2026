# Para ti ♡

Website romântico pronto para GitHub Pages.

## Publicar
1. Cria um repositório público no GitHub.
2. Faz upload de todo o conteúdo desta pasta (não apenas o ZIP).
3. Settings → Pages.
4. Source: Deploy from a branch.
5. Branch: main, folder: / (root).
6. Save.

## Personalizar
O texto está em `index.html`.
As fotografias estão em `images/`.
